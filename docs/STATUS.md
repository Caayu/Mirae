## Features

| Area | State |
|---|---|
| Canvas | Sparse 256×256 tiles, pan/zoom (1/64–256×)/rotate, mipmapped seam-free display, crisp magnification |
| Input | Windows Ink (pressure, tilt, rotation, eraser end, full history, QPC timestamps, HIMETRIC sub-pixel), mouse; pen passthrough to UI |
| Stroke processing | Velocity, jitter filter, stabilizers (none, moving average, exponential, One Euro default), interpolation (linear, centripetal Catmull–Rom default, Bézier), sample-rate-invariant spacing, start/end tapers with live tail |
| Presets | Versioned JSON (v1), migration, lenient loading, validation; 8 built-ins: ink pen, pencil, soft round, marker, airbrush, chalk, calligraphy, eraser |
| Effectors | 10 sources × 6 combine modes per property, monotone curves, ≤ 64 per property |
| Tips | Round, rectangle (hardness, aspect, angle, flips); image tips (built-in speckle/bristle/charcoal generated by code, or embedded grayscale) with mip pyramids |
| Textures | Canvas-space paper (fine, rough, chalk) — multiply/subtract/height modes |
| Scatter | Perpendicular/radial, count, rotation and scale jitter, effector-driven amount |
| Airbrush | Time instants independent of frame rate; rest detection with delivery-lag compensation; dwell-time flow while moving |
| Eraser | Destination-out through the same engine; stylus eraser end switches automatically; `E` for the mouse |
| UI | egui side panel: presets, parameters, stroke settings, tip/scatter/texture, pressure curve editor, effector editor |
| Golden corpus | 8 sheets × 12 trajectories, tolerant comparison, explicit updates |
| Performance | 0 allocations per sample/dab (sequential path, tested; parallel path: amortized rayon queue blocks); ~120 Mpx/s large hard dabs single-thread; ~3× parallel at 500 px; 0.107 ms per composed tile |
| Document | One raster layer in practice (layer stack exists; `Normal` blend only); no undo; no file I/O |

## Current limitations

See [TECHNICAL_DEBT.md](TECHNICAL_DEBT.md) for the full list with
priorities. Most relevant: no physical tablet validation; 8-bit storage
(banding); document size bounded by GPU texture size; no undo/redo; no
document I/O; preset edits not persisted; UI unpolished.

## Phase 3.5 outcome

Audit and refactors (no new features): workspace metadata and lints,
Ink API without raw handles, smaller brush API, preset hardening, domain
rule moved out of app/UI, golden hygiene, property tests, enforced crate
boundaries, crate/API docs, architecture docs, ADRs, handoff docs, check
script. Details: [CHANGELOG.md](../CHANGELOG.md).
